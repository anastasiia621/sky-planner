# Sky Planner 🌤

**Ежедневник, который сверяет планы с прогнозом погоды.**
A planner that checks your plans against the weather forecast.

🔗 **Сайт / Live:** https://weathergout.netlify.app

## Что умеет

- **Прогноз на 7 дней** для любого города и прогноз для конкретного места плана (пляж, гора, причал).
- **Проверка планов по погоде**: велосипед, пляж, лодка, параплан, воздушный шар и другие занятия, у каждого свои правила (дождь, ветер, жара).
- **Умный перенос**: «В 18:00 будет дождь, лучше погулять перед работой, в 08:00–10:00».
- **Дорога**: пешком, самокат, велосипед или машина, время в пути, когда выйти и удобно ли по погоде.
- **«Будешь работать из дома?»** и ярлыки мест (дом, офис, зал).
- **Идеи на неделю** для Фетхие, Каппадокии, Антальи и Стамбула: занятия по погоде, кафе и завтраки, поездки. С фото, билетами и подсказками, когда меньше туристов.
- **Живая проверка в форме**: меняешь время и сразу видишь, подходит ли погода.
- Уведомления с советами, редактирование планов, тёмная тема, версия для телефона.

## Как устроено

| Файл | Что это |
|---|---|
| `site/index.html` | Весь сайт: разметка, стили и код в одном файле |
| `netlify.toml` | Настройки Netlify: публиковать папку `site/` |
| `tools/serve.js` | Локальный сервер для просмотра: `node tools/serve.js` → http://localhost:8765 |

Данные (планы, места) хранятся только в браузере пользователя (`localStorage`), сервера с базой нет.

Внешние сервисы, все бесплатные и без ключей:
- [Open-Meteo](https://open-meteo.com/): прогноз погоды и поиск городов
- [Photon](https://photon.komoot.io/) / [OpenStreetMap](https://www.openstreetmap.org/copyright): поиск адресов
- [Wikipedia](https://www.wikipedia.org/): фото мест

## Как обновлять

1. Правки вносятся в `site/index.html`.
2. Сохраняем версию в Git (`git add`, `git commit`) и отправляем на GitHub (`git push`).
3. Netlify сам замечает изменения и обновляет сайт.
